# Krace
A kid-friendly top-down city driving game. No install, no build tools.
1. Open `index.html` in any browser (double-click it). Drive with the arrow keys or W A S D.
2. Everything you can change is in `config.js`: cars, heroes, the city map, speeds.
3. To add a car or hero, copy an entry in `config.js`, give it a new `id` and `name`, and change the numbers.
4. To use your own drawing, save it as a PNG (car/hero pointing UP), put it in an `images/` folder and set `image: "images/my-car.png"` in config.js.
5. Try a different car without editing: open `index.html?car=speedy-blue`. Everything is original and non-violent: bumps just bounce softly.
